# SM-Scope Reproducibility

Reproducibility repository for **"Metabolomics-driven spatial multi-omics integration with SM-Scope reveals importance of metabotypes and tissue architecture"**.

This repo is a collection of standalone analysis scripts (R, Python, Groovy, Julia, Bash), not an installable package. Run scripts individually, typically from within their own directory as the working directory.

## Repository layout

- **`Analysis_scripts/Upstream/`**: raw data to integrated multi-omics objects: METASPACE annotation QC, QuPath/Baysor cell segmentation, `spatialdata`/AnnData assembly, pixel-to-cell metabolite deconvolution, Allen Brain Atlas region registration, and the combined multi-assay Seurat object.
- **`Analysis_scripts/Downstream/`**: biological analysis on the merged Seurat object: per-modality clustering/DE, spatial niches and brain regions, SpatialGlue modality integration, MISTY spatial interaction modeling, DIALOGUE multicellular programs, gene–metabolite correlation and pathway/reaction networks, enrichment. `Generate_Supp_Tables.R` writes every supplementary table to `Output/Supp_Tables/`.
- **`Utils/`**: shared helpers sourced by nearly every script: `utils.R`, `Plotting.R`, `colors.R`, `Figure_analysis.R`, `SpaceM_Deconv_methods.py`.
- **`Fig_scripts/`**: one script per manuscript figure (`Figure_2.R`–`Figure_6.R`), loading pre-computed results from `Data/Figure N/` and writing plots to `Manuscript/Figures/{Main,Supp}` (author's machine only). `Generate_Figure_Numbers.R` writes every manuscript-text number to `Output/Numbers/`.
- **`Data/`**: intermediate and final analysis objects (`.rds`, `.h5ad`, network files), organized by figure number. Not committed to git; see [Data/README.md](Data/README.md) for how to download it from Zenodo.
- **`Output/`**: the supplementary tables and manuscript numbers generated by the two scripts above, committed to git.
- **`envs/`**: package versions for the environments used to run this pipeline. See [envs/README.md](envs/README.md).

## Setup

There is no single environment manifest; this pipeline spans R, Python, Groovy (QuPath), Julia (Baysor), and Bash/SLURM.

- **R**: run `Rscript <file>.R`, or source it from RStudio, with the working directory set to the script's own folder. Package versions: [`envs/r_package_versions.csv`](envs/r_package_versions.csv).
- **Python**: each `Upstream/` stage used its own conda environment. See [envs/README.md](envs/README.md) for which one and how to recreate it.
- **Groovy**: run `Analysis_scripts/Upstream/QuPath_Cell_Detection/binarize_qupath_detections.groovy` from within QuPath's script editor against a QuPath project.
- **Julia**: `Analysis_scripts/Upstream/Baysor_cell_segmentation/baysor_dev_seg_run` runs inside a `Baysor` conda environment.
- **Cluster jobs**: some scripts run via SLURM (`sbatch`) or inside Singularity containers (see `run_dialogue_singularity.sh`).

## Data

`Data/` is hosted on Zenodo rather than committed to this repo (too large for GitHub). Download it with:

```bash
zenodo_download_data.sh <record_id>
```

See [Data/README.md](Data/README.md) for the expected layout and update workflow.
